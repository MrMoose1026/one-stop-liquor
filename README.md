# One Stop Liquor

A three-page store website built with HTML, CSS and JavaScript, using eight photos taken inside and outside the store.

## Files

- `index.html` — Homepage.
- `selection.html` — Wine, spirits, beer and mixers gallery.
- `location.html` — New location, photos, hours and contact section.
- `styles.css` — Shared styling and responsive layouts.
- `script.js` — Mobile menu and map/contact behavior.
- `store-details.js` — Address and phone configuration.
- `images/` — All eight optimized store photos.

## Open and edit

Download or clone this repository, then open `index.html` in a browser. No build tools or dependency installation are required. Keep the files and `images` folder together.

## Complete the location details

Fill in the four empty values in `store-details.js` once the details are confirmed. The location page will then display the address, embedded Google map, directions link and clickable phone number. Until then, it explicitly shows that those details are awaiting confirmation.

Product photos show the selection at the time they were taken, not live inventory.
